Chapter 1: Database

1. What is Data?

Data is raw facts and figures that have no meaning on their own. It can be numbers, text, images, audio, or video.

Examples of Data:

  • 101
  • Nirbhay
  • 85%
  • 9876543210
  • 01/01/2026
Data becomes useful only after processing. For example: 85 is data. "Student scored 85 marks in DBMS" is information.

Example in Table Form (Raw Data)

Roll No Name Marks
101 Rahul 85
102 Priya 90

2. What is a Database?

A Database is an organized collection of related data stored in a structured format so that it can be easily accessed, managed, and updated.

A database stores data in tables (rows and columns).

Simple Definition:

Database = Organized Collection of Related Data

Example:

In a college:

  • Student Records
  • Faculty Details
  • Course Information
  • Exam Results
All these together form a College Database.

SQL Example:

CREATE TABLE Students (
    RollNo INT PRIMARY KEY,
    Name VARCHAR(50),
    Marks INT
);

INSERT INTO Students VALUES (101, 'Rahul', 85);
INSERT INTO Students VALUES (102, 'Priya', 90);

SELECT * FROM Students;

3. Characteristics of Database

1. Organized Structure

Data is stored in tables with rows and columns.

2. Data Integrity

Ensures data is accurate and consistent.

3. Data Security

Only authorized users can access data.

4. Reduced Redundancy

Duplicate data is minimized.

5. Data Sharing

Multiple users can access data simultaneously.

6. Backup and Recovery

Data can be recovered in case of failure.

4. Types of Database

1. Relational Database (RDBMS)

Stores data in tables. Uses SQL.

Example: MySQL, Oracle

2. NoSQL Database

Stores data in JSON, key-value, document form.

Example: MongoDB

3. Centralized Database

Stored in one central location.

4. Distributed Database

Stored across multiple locations.

5. Real World Examples of Databases

  • Banking System – Customer accounts, transactions
  • Hospital Management – Patient records
  • Library System – Books and members
  • E-commerce – Products, Orders, Customers
  • College ERP System – Students, Marks, Attendance

6. File System vs Database

File System Database System
Data stored in separate files Data stored in structured tables
High redundancy Reduced redundancy
No proper security Strong security
Difficult data retrieval Easy data retrieval using SQL
No relationships Supports relationships (Primary Key, Foreign Key)

File System Example:

student.txt marks.txt fees.txt

Each file is separate → data duplication possible.

Database Example:

CREATE TABLE Students (
    RollNo INT PRIMARY KEY,
    Name VARCHAR(50)
);

CREATE TABLE Marks (
    RollNo INT,
    Subject VARCHAR(50),
    Marks INT,
    FOREIGN KEY (RollNo) REFERENCES Students(RollNo)
);

Here, relationships reduce duplication.
