Chapter 10: SQL Functions

What are SQL Functions?

SQL Functions are built-in operations provided by the database system that perform calculations or manipulations on data. They help process values and return a result.

Functions are commonly used inside the SELECT statement to transform data. 
SELECT function_name(column)
FROM table_name;

1. String Functions

String functions are used to manipulate text data stored in database columns.

Function Description Example
UPPER() Convert text to uppercase SELECT UPPER(Name) FROM Students;
LOWER() Convert text to lowercase SELECT LOWER(Name) FROM Students;
LENGTH() Returns length of string SELECT LENGTH(Name) FROM Students;
CONCAT() Combine multiple strings SELECT CONCAT(FirstName, LastName) FROM Employees;
SUBSTRING() Extract part of a string SELECT SUBSTRING(Name,1,3) FROM Students;
TRIM() Remove spaces SELECT TRIM(Name) FROM Students;

Example

SELECT 
UPPER(Name),
LENGTH(Name)
FROM Students;

2. Numeric Functions

Numeric functions perform mathematical calculations on numeric values.

Function Description Example
ABS() Returns absolute value SELECT ABS(-10);
ROUND() Rounds a number SELECT ROUND(45.67);
CEILING() Returns smallest integer ≥ value SELECT CEILING(4.2);
FLOOR() Returns largest integer ≤ value SELECT FLOOR(4.8);
POWER() Returns exponent value SELECT POWER(2,3);
MOD() Returns remainder SELECT MOD(10,3);

Example

SELECT 
ROUND(Marks),
ABS(-25)
FROM Students;

3. Date Functions

Date functions operate on date and time values. They help retrieve or manipulate date information.

Function Description Example
NOW() Returns current date and time SELECT NOW();
CURDATE() Returns current date SELECT CURDATE();
YEAR() Extract year SELECT YEAR(OrderDate) FROM Orders;
MONTH() Extract month SELECT MONTH(OrderDate) FROM Orders;
DAY() Extract day SELECT DAY(OrderDate) FROM Orders;
DATEDIFF() Difference between two dates SELECT DATEDIFF('2026-12-31','2026-01-01');

Example

SELECT 
OrderID,
YEAR(OrderDate),
MONTH(OrderDate)
FROM Orders;

4. Conversion Functions

Conversion functions convert data from one data type to another.

Function Description Example
CAST() Convert value to another datatype SELECT CAST('2026' AS INT);
CONVERT() Convert datatype SELECT CONVERT(INT,'123');
TO_CHAR() Convert number/date to string SELECT TO_CHAR(Salary);
TO_DATE() Convert string to date SELECT TO_DATE('2026-05-10');

Example

SELECT 
CAST('100' AS INT) + 50;

The string '100' is converted to an integer before performing the calculation.

Example Using Multiple Functions

SELECT 
UPPER(Name),
ROUND(Salary),
YEAR(HireDate)
FROM Employees;

This query:

  • Converts employee names to uppercase
  • Rounds salary values
  • Extracts the hiring year
