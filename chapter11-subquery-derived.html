Chapter 11: Subquery & Derived Table

What is a Subquery?

A Subquery is a query written inside another SQL query. It is also known as an inner query or nested query.

A subquery is executed first and its result is used by the outer query.

Basic Syntax

SELECT column_name
FROM table_name
WHERE column_name operator
      (SELECT column_name FROM table_name);

Example

Find students who scored more than the average marks.

SELECT Name, Marks
FROM Students
WHERE Marks > (
      SELECT AVG(Marks)
      FROM Students
);

Explanation:

  • The inner query calculates the average marks.
  • The outer query returns students whose marks are greater than that average.

Types of Subqueries

Subqueries can be categorized based on how many values they return and how they interact with the outer query.

1. Single Row Subquery

A single-row subquery returns only one row as output. It is usually used with operators like =, >, <, >=, <=.

Example

Find students who scored higher than the average marks.

SELECT Name, Marks
FROM Students
WHERE Marks > (
      SELECT AVG(Marks)
      FROM Students
);

The inner query returns a single value (average marks).

2. Multiple Row Subquery

A multi-row subquery returns multiple rows. These queries are used with operators like IN, ANY, ALL.

Example

Find students who belong to departments that exist in another table.

SELECT Name
FROM Students
WHERE Department IN (
      SELECT Department
      FROM Departments
);

Explanation:

  • The inner query returns multiple department names.
  • The outer query finds students belonging to those departments.

3. Correlated Subquery

A correlated subquery depends on the outer query. It is executed once for each row processed by the outer query.

Example

Find employees who earn more than the average salary of their department.

SELECT Name, Salary, Department
FROM Employees E
WHERE Salary > (
      SELECT AVG(Salary)
      FROM Employees
      WHERE Department = E.Department
);

Explanation:

  • The outer query processes each employee.
  • The inner query calculates average salary for that employee's department.
  • If the employee's salary is higher than the department average, the row is returned.

Derived Table

A Derived Table is a temporary table created from a subquery inside the FROM clause. It behaves like a normal table and can be used in queries.

Syntax

SELECT *
FROM (
      SELECT column1, column2
      FROM table_name
     ) AS temp_table;

Example

Calculate average marks of departments using a derived table.

SELECT Department, AVG(Marks)
FROM (
      SELECT Department, Marks
      FROM Students
     ) AS TempTable
GROUP BY Department;

The subquery creates a temporary table called TempTable. The outer query then performs operations on this table.

Inline View

An Inline View is another name for a derived table. It is commonly used in Oracle and some other database systems.

Inline views are subqueries written inside the FROM clause.

Example

SELECT *
FROM (
      SELECT Name, Marks
      FROM Students
      WHERE Marks > 80
     ) AS HighScorers;

Explanation:

  • The inner query selects students with marks greater than 80.
  • The outer query treats the result as a temporary table called HighScorers.

Advantages of Subqueries

  • Make complex queries easier to write.
  • Allow dynamic filtering of data.
  • Improve readability of SQL statements.
  • Useful for calculations and comparisons.
