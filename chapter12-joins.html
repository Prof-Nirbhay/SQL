Chapter 12: SQL Joins

What are SQL Joins?

SQL Joins are used to combine rows from two or more tables based on a related column between them. They allow data from multiple tables to be retrieved in a single query.

Joins are essential when database information is distributed across multiple tables.

Example Tables

Students Table

StudentID Name DepartmentID
1 Rahul 101
2 Priya 102
3 Aman 101
4 Neha 103

Departments Table

DepartmentID DepartmentName
101 Computer Science
102 Information Technology
104 Electronics

1. INNER JOIN

INNER JOIN returns only the rows where there is a match in both tables.

Syntax

SELECT columns
FROM table1
INNER JOIN table2
ON table1.column = table2.column;

Example

SELECT Students.Name, Departments.DepartmentName
FROM Students
INNER JOIN Departments
ON Students.DepartmentID = Departments.DepartmentID;

Output

Name DepartmentName
Rahul Computer Science
Priya Information Technology
Aman Computer Science

Student Neha is not included because DepartmentID 103 does not exist in the Departments table.

2. LEFT JOIN

LEFT JOIN returns all rows from the left table and matching rows from the right table. If no match exists, NULL values are returned.

Syntax

SELECT columns
FROM table1
LEFT JOIN table2
ON table1.column = table2.column;

Example

SELECT Students.Name, Departments.DepartmentName
FROM Students
LEFT JOIN Departments
ON Students.DepartmentID = Departments.DepartmentID;

Output

Name DepartmentName
Rahul Computer Science
Priya Information Technology
Aman Computer Science
Neha NULL

Neha appears even though her department does not exist in the Departments table.

3. RIGHT JOIN

RIGHT JOIN returns all rows from the right table and matching rows from the left table.

Syntax

SELECT columns
FROM table1
RIGHT JOIN table2
ON table1.column = table2.column;

Example

SELECT Students.Name, Departments.DepartmentName
FROM Students
RIGHT JOIN Departments
ON Students.DepartmentID = Departments.DepartmentID;

Output

Name DepartmentName
Rahul Computer Science
Priya Information Technology
Aman Computer Science
NULL Electronics

Electronics department appears even though no student belongs to it.

4. FULL JOIN

FULL JOIN returns all rows from both tables. If there is no match, NULL values appear.

Syntax

SELECT columns
FROM table1
FULL JOIN table2
ON table1.column = table2.column;

Result Concept

Combines the results of LEFT JOIN and RIGHT JOIN.

5. SELF JOIN

SELF JOIN is used when a table joins with itself. This is useful for hierarchical relationships.

Example Table

EmployeeID Name ManagerID
1 Raj NULL
2 Priya 1
3 Aman 1

Example Query

SELECT A.Name AS Employee, B.Name AS Manager
FROM Employees A
LEFT JOIN Employees B
ON A.ManagerID = B.EmployeeID;

6. CROSS JOIN

CROSS JOIN returns the Cartesian product of two tables. Each row of the first table is combined with every row of the second table.

Syntax

SELECT *
FROM table1
CROSS JOIN table2;

Example

If table1 has 3 rows and table2 has 4 rows, the result will have 12 rows.

Comparison of Join Types

Join Type Description
INNER JOIN Returns matching rows from both tables
LEFT JOIN Returns all rows from left table
RIGHT JOIN Returns all rows from right table
FULL JOIN Returns all rows from both tables
SELF JOIN Table joins with itself
CROSS JOIN Cartesian product of tables
