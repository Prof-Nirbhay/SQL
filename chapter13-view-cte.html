Chapter 13: SQL Views and Common Table Expressions (CTE)

What is a View?

A View in SQL is a virtual table that is created using a SELECT query. It does not store data itself; instead, it displays data from one or more tables.

A View acts like a saved SQL query that can be reused multiple times.

Example Base Table

StudentID Name Marks
1 Rahul 85
2 Priya 92
3 Aman 75

Advantages of Views

Advantage Description
Security Restrict access to specific columns or rows
Simplicity Complex queries can be simplified
Data Abstraction Hide internal database structure
Reusability Reuse frequently used queries
Consistency Ensure uniform data presentation

Create a View

Syntax

CREATE VIEW view_name AS
SELECT column1, column2
FROM table_name
WHERE condition;

Example

CREATE VIEW TopStudents AS
SELECT Name, Marks
FROM Students
WHERE Marks > 80;

Using the View

SELECT * FROM TopStudents;

Updating a View

If the view allows updates, you can modify data through it. Changes will affect the original table.

Example

UPDATE TopStudents
SET Marks = 95
WHERE Name = 'Rahul';

Modify (Alter) a View

Syntax

CREATE OR REPLACE VIEW TopStudents AS
SELECT Name, Marks
FROM Students
WHERE Marks > 85;

Drop a View

Syntax

DROP VIEW TopStudents;

What is a CTE (Common Table Expression)?

A Common Table Expression (CTE) is a temporary result set defined within a SQL query. It improves readability and simplifies complex queries.

CTE exists only during query execution and is not stored permanently in the database.

Basic Syntax

WITH cte_name AS
(
SELECT column1, column2
FROM table_name
WHERE condition
)

SELECT * FROM cte_name;

Example

WITH HighMarks AS
(
SELECT Name, Marks
FROM Students
WHERE Marks > 80
)

SELECT * FROM HighMarks;

Recursive CTE

A Recursive CTE is used to perform hierarchical or recursive queries such as organizational charts or tree structures.

Structure of Recursive CTE

WITH RecursiveCTE AS
(
-- Anchor Query
SELECT column1
FROM table

UNION ALL

-- Recursive Query
SELECT column1
FROM table
JOIN RecursiveCTE
ON condition
)

SELECT * FROM RecursiveCTE;

Example: Employee Hierarchy

EmployeeID Name ManagerID
1 Raj NULL
2 Priya 1
3 Aman 2

Recursive Query

WITH EmployeeHierarchy AS
(
SELECT EmployeeID, Name, ManagerID
FROM Employees
WHERE ManagerID IS NULL

UNION ALL

SELECT e.EmployeeID, e.Name, e.ManagerID
FROM Employees e
JOIN EmployeeHierarchy eh
ON e.ManagerID = eh.EmployeeID
)

SELECT * FROM EmployeeHierarchy;

This query retrieves the full hierarchy starting from the top-level manager.

View vs CTE

Feature View CTE
Storage Stored in database Temporary
Reuse Reusable Only within query
Performance Can improve query reuse Better readability
Complex Queries Moderate Excellent
