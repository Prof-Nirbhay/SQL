Chapter 14: SQL Window Functions

What are Window Functions?

Window functions perform calculations across a set of table rows that are related to the current row. Unlike GROUP BY, window functions do not collapse rows into a single result. They allow calculations while keeping the original rows.

Window functions are commonly used for ranking, running totals, and analytical queries.

Example Table: Employees

EmployeeID Name Department Salary
1 Rahul IT 60000
2 Priya IT 75000
3 Aman HR 50000
4 Neha HR 65000
5 Karan IT 75000

OVER Clause

The OVER() clause defines the window or set of rows used for the calculation.

Syntax

FUNCTION_NAME() OVER (
    PARTITION BY column
    ORDER BY column
)

PARTITION BY

PARTITION BY divides rows into groups (partitions). The window function is applied separately to each partition.

Example

SELECT Name, Department, Salary,
RANK() OVER (PARTITION BY Department ORDER BY Salary DESC) AS DeptRank
FROM Employees;

Output

Name Department Salary DeptRank
Priya IT 75000 1
Karan IT 75000 1
Rahul IT 60000 3
Neha HR 65000 1
Aman HR 50000 2

ORDER BY inside OVER

ORDER BY determines the order of rows inside the window function calculation.

Example

SELECT Name, Salary,
ROW_NUMBER() OVER (ORDER BY Salary DESC) AS RowNum
FROM Employees;

ROW_NUMBER()

ROW_NUMBER assigns a unique number to each row. Even if values are the same, row numbers will always be unique.

Example

SELECT Name, Salary,
ROW_NUMBER() OVER (ORDER BY Salary DESC) AS RowNumber
FROM Employees;

Output

Name Salary RowNumber
Priya 75000 1
Karan 75000 2
Neha 65000 3
Rahul 60000 4
Aman 50000 5

RANK()

RANK assigns ranking numbers to rows. If two rows have the same value, they receive the same rank, and the next rank is skipped.

Example

SELECT Name, Salary,
RANK() OVER (ORDER BY Salary DESC) AS RankNumber
FROM Employees;

Output

Name Salary Rank
Priya 75000 1
Karan 75000 1
Neha 65000 3
Rahul 60000 4
Aman 50000 5

DENSE_RANK()

DENSE_RANK is similar to RANK but does not skip rank numbers.

Example

SELECT Name, Salary,
DENSE_RANK() OVER (ORDER BY Salary DESC) AS DenseRank
FROM Employees;

Output

Name Salary DenseRank
Priya 75000 1
Karan 75000 1
Neha 65000 2
Rahul 60000 3
Aman 50000 4

Difference Between ROW_NUMBER, RANK and DENSE_RANK

Function Duplicate Handling Skip Numbers
ROW_NUMBER No duplicates No skipping
RANK Same rank for duplicates Yes
DENSE_RANK Same rank for duplicates No
