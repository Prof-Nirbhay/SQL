Chapter 15: SQL CASE Statement

What is CASE?

The CASE statement in SQL is used to perform conditional logic within a query. It works similar to IF-ELSE statements in programming languages.

CASE allows you to return different values depending on conditions.

General Syntax of CASE

CASE
    WHEN condition1 THEN result1
    WHEN condition2 THEN result2
    ELSE result
END

The CASE statement checks conditions sequentially and returns the first matching result.

Example Table: Students

ID Name Marks
1 Rahul 85
2 Priya 92
3 Aman 65
4 Neha 40

1. Simple CASE

Simple CASE compares an expression with multiple values.

Syntax

CASE column_name
    WHEN value1 THEN result1
    WHEN value2 THEN result2
    ELSE result
END

Example

SELECT Name, Marks,
CASE Marks
    WHEN 92 THEN 'Topper'
    WHEN 85 THEN 'Excellent'
    ELSE 'Other'
END AS Result
FROM Students;

This query checks the exact value of Marks and returns the corresponding label.

2. Searched CASE

Searched CASE evaluates multiple logical conditions instead of specific values.

Syntax

CASE
    WHEN condition THEN result
    WHEN condition THEN result
    ELSE result
END

Example

SELECT Name, Marks,
CASE
    WHEN Marks >= 90 THEN 'A Grade'
    WHEN Marks >= 75 THEN 'B Grade'
    WHEN Marks >= 50 THEN 'C Grade'
    ELSE 'Fail'
END AS Grade
FROM Students;

Output

Name Marks Grade
Rahul 85 B Grade
Priya 92 A Grade
Aman 65 C Grade
Neha 40 Fail

3. CASE inside SELECT

CASE is commonly used inside the SELECT clause to create calculated or categorized columns.

Example

SELECT Name, Salary,
CASE
    WHEN Salary >= 70000 THEN 'High Salary'
    WHEN Salary >= 50000 THEN 'Medium Salary'
    ELSE 'Low Salary'
END AS SalaryCategory
FROM Employees;

This query creates a new column called SalaryCategory based on salary ranges.

4. CASE inside ORDER BY

CASE can also control the sorting order of query results.

Example Table: Employees

Name Department
Rahul IT
Priya HR
Aman Finance

Query

SELECT Name, Department
FROM Employees
ORDER BY
CASE Department
    WHEN 'IT' THEN 1
    WHEN 'HR' THEN 2
    WHEN 'Finance' THEN 3
END;

This query sorts departments in a custom order instead of alphabetical order.

CASE with Aggregate Functions

CASE can be used with aggregate functions to perform conditional calculations.

Example

SELECT
COUNT(CASE WHEN Marks >= 50 THEN 1 END) AS PassedStudents,
COUNT(CASE WHEN Marks < 50 THEN 1 END) AS FailedStudents
FROM Students;

This query counts the number of passed and failed students.

Advantages of CASE

Advantage Description
Conditional Logic Add decision-making logic inside queries
Readable Queries Makes complex conditions easier to understand
Flexible Works with SELECT, ORDER BY, GROUP BY, and aggregates
Powerful Reporting Useful for data categorization
