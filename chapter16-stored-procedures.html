Chapter 16: SQL Stored Procedures

What is a Stored Procedure?

A Stored Procedure is a precompiled collection of SQL statements stored in the database. It can be executed whenever needed to perform a specific task.

Stored procedures allow developers to reuse SQL code and improve database performance.

Instead of writing the same SQL query repeatedly, we create a stored procedure once and call it whenever needed.

Advantages of Stored Procedures

Advantage Description
Code Reusability Write once and reuse multiple times
Better Performance Stored procedures are compiled and optimized
Security Users can execute procedures without direct table access
Reduced Network Traffic Only procedure call is sent instead of full SQL query
Maintainability Business logic stored centrally in database

Example Table

EmployeeID Name Department Salary
1 Rahul IT 60000
2 Priya HR 55000
3 Aman Finance 50000

Create Stored Procedure

Syntax

CREATE PROCEDURE procedure_name
AS
BEGIN
    SQL statements
END;

Example

CREATE PROCEDURE GetEmployees
AS
BEGIN
    SELECT * FROM Employees;
END;

This procedure retrieves all records from the Employees table.

Stored Procedure with Parameters

Stored procedures can accept parameters to make them more dynamic.

Syntax

CREATE PROCEDURE procedure_name
    @parameter datatype
AS
BEGIN
    SQL statements
END;

Example

CREATE PROCEDURE GetEmployeeByDept
    @Dept VARCHAR(50)
AS
BEGIN
    SELECT * 
    FROM Employees
    WHERE Department = @Dept;
END;

This procedure returns employees belonging to a specific department.

Calling (Executing) a Stored Procedure

Syntax

EXEC procedure_name;

Example

EXEC GetEmployees;

Calling Procedure with Parameter

EXEC GetEmployeeByDept 'IT';

This query retrieves employees from the IT department.

Drop Stored Procedure

If a stored procedure is no longer needed, it can be removed from the database.

Syntax

DROP PROCEDURE procedure_name;

Example

DROP PROCEDURE GetEmployees;

Summary

Concept Description
Stored Procedure Reusable block of SQL code
CREATE PROCEDURE Create new stored procedure
Parameters Allow dynamic input values
EXEC Execute stored procedure
DROP PROCEDURE Delete stored procedure
