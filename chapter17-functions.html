Chapter 17: SQL User Defined Functions

What is a User Defined Function (UDF)?

A User Defined Function (UDF) is a function created by the user in SQL to perform a specific task. It accepts input parameters, processes them, and returns a value.

Unlike stored procedures, SQL functions must return a value.

Functions help in simplifying complex queries and reusing logic multiple times.

Types of User Defined Functions

Type Description
Scalar Function Returns a single value
Table Valued Function Returns a table

1. Scalar Function

A Scalar Function returns a single value such as number, string, or date.

Syntax

CREATE FUNCTION function_name (@parameter datatype)
RETURNS datatype
AS
BEGIN
    DECLARE @result datatype

    -- SQL logic here

    RETURN @result
END

Example

CREATE FUNCTION GetBonus (@salary INT)
RETURNS INT
AS
BEGIN
    RETURN @salary * 10 / 100
END

Using the Function

SELECT Name, Salary,
dbo.GetBonus(Salary) AS Bonus
FROM Employees;

This function calculates a 10% bonus for each employee.

2. Table Valued Function

A Table Valued Function returns a table as a result.

Syntax

CREATE FUNCTION function_name(@parameter datatype)
RETURNS TABLE
AS
RETURN
(
    SELECT columns
    FROM table
    WHERE condition
)

Example

CREATE FUNCTION GetEmployeesByDept(@Dept VARCHAR(50))
RETURNS TABLE
AS
RETURN
(
    SELECT *
    FROM Employees
    WHERE Department = @Dept
)

Using the Function

SELECT * 
FROM dbo.GetEmployeesByDept('IT');

This function returns all employees belonging to a particular department.

Difference Between Stored Procedure and Function

Feature Stored Procedure Function
Return Value May or may not return value Must return value
Usage Executed using EXEC Used inside SQL queries
Result Can return multiple outputs Returns single value or table
Data Modification Can modify database data Usually used for calculation
Calling Method EXEC procedure_name SELECT function_name()

Example Comparison

Stored Procedure

EXEC GetEmployees;

Function

SELECT dbo.GetBonus(50000);

The stored procedure executes tasks, while the function returns a value inside a query.

Advantages of SQL Functions

Advantage Description
Code Reusability Functions can be reused in multiple queries
Cleaner Queries Complex calculations can be simplified
Modular Programming Logic can be separated into small reusable functions
Better Maintenance Logic changes only in one place
