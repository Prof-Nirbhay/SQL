Chapter 18: Advanced SQL Concepts

1. Indexing

An Index is a database object that improves the speed of data retrieval operations on a table. It works similar to the index of a book, allowing the database to find rows quickly.

Advantages

  • Faster query performance
  • Efficient searching
  • Improved sorting and filtering

Syntax

CREATE INDEX index_name
ON table_name(column_name);

Example

CREATE INDEX idx_employee_name
ON Employees(Name);

2. Normalization

Normalization is the process of organizing data in a database to reduce redundancy and improve data integrity.

Main Normal Forms

Normal Form Description
1NF Remove repeating groups and ensure atomic values
2NF Remove partial dependency
3NF Remove transitive dependency

Example

Instead of storing department information repeatedly in the Students table, create a separate Department table.

3. Transactions

A Transaction is a sequence of SQL operations executed as a single logical unit.

Example

BEGIN TRANSACTION;

UPDATE Accounts
SET Balance = Balance - 500
WHERE AccountID = 1;

UPDATE Accounts
SET Balance = Balance + 500
WHERE AccountID = 2;

COMMIT;

If any step fails, the transaction can be rolled back.

4. ACID Properties

ACID properties ensure reliable database transactions.

Property Description
Atomicity All operations succeed or none
Consistency Database remains in valid state
Isolation Transactions do not interfere
Durability Changes persist even after system crash

5. Triggers

A Trigger is a special type of stored procedure that automatically executes when a specific event occurs.

Example Events

  • INSERT
  • UPDATE
  • DELETE

Syntax

CREATE TRIGGER trigger_name
AFTER INSERT
ON Employees
FOR EACH ROW
BEGIN
    INSERT INTO AuditLog VALUES ('Employee inserted');
END;

6. Execution Plan

An Execution Plan shows how the database engine executes a SQL query. It helps developers understand query performance and identify slow operations.

Example

EXPLAIN SELECT * FROM Employees WHERE Salary > 50000;

This command shows how the database searches tables and uses indexes.

7. SQL Optimization

SQL optimization improves query performance and reduces execution time.

Best Practices

  • Use indexes wisely
  • Avoid SELECT *
  • Use proper WHERE conditions
  • Use joins instead of subqueries when possible
  • Limit result sets using LIMIT

8. SQL Injection Basics

SQL Injection is a security vulnerability where attackers manipulate SQL queries by injecting malicious code.

Example Vulnerable Query

SELECT * FROM Users
WHERE username = 'user'
AND password = 'password';

Injected Input

' OR '1'='1

This can bypass authentication and allow unauthorized access.

Prevention Techniques

  • Use prepared statements
  • Validate user inputs
  • Use parameterized queries
  • Apply least privilege database access
