Chapter 2: DBMS (Database Management System)

1. What is DBMS?

A DBMS (Database Management System) is software that allows users to create, manage, store, retrieve, and control data in a database.

It acts as an interface between the user and the database.

Database = Collection of data DBMS = Software to manage that data

Example:

If Database is a library, then DBMS is the librarian who manages books.

Simple Diagram Concept:

User → DBMS → Database

SQL Example:

CREATE DATABASE College;

USE College;

CREATE TABLE Students (
    RollNo INT PRIMARY KEY,
    Name VARCHAR(50),
    Marks INT
);

INSERT INTO Students VALUES (101, 'Rahul', 85);

SELECT * FROM Students;

2. Functions of DBMS

1. Data Storage Management

Stores and organizes data efficiently.

2. Data Retrieval

Allows users to retrieve data using queries.

3. Data Security

Provides authentication and authorization.

4. Data Integrity

Maintains accuracy and consistency of data.

5. Concurrency Control

Allows multiple users to access data simultaneously.

6. Backup and Recovery

Restores data in case of failure.

7. Transaction Management

Ensures ACID properties (Atomicity, Consistency, Isolation, Durability).

3. Advantages of DBMS

  • Reduced Data Redundancy
  • Improved Data Consistency
  • Better Security
  • Data Sharing
  • Backup & Recovery Support
  • Integrity Constraints
  • Centralized Control

4. Disadvantages of DBMS

  • High Cost (Software & Hardware)
  • Complexity
  • Requires Skilled Staff
  • Performance Overhead
  • Risk of Central Failure

5. Types of DBMS

1. Hierarchical DBMS

Data organized in tree structure (Parent → Child).

Example: Organization structure

2. Network DBMS

Data organized in graph structure (Many-to-Many relationships).

3. Relational DBMS (RDBMS)

Data stored in tables (rows & columns). Uses SQL.

4. Object-Oriented DBMS (OODBMS)

Stores data as objects (like in OOP).

Comparison of DBMS Types

Type Structure Relationship Flexibility
Hierarchical Tree One-to-Many Low
Network Graph Many-to-Many Medium
Relational Table Uses Keys High
Object-Oriented Objects Object References Very High
