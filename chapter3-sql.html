Chapter 3: SQL (Structured Query Language)

1. What is SQL?

SQL (Structured Query Language) is a standard programming language used to communicate with relational databases.

It is used to create, retrieve, update, and delete data from a database.

Database stores data. DBMS manages data. SQL is the language used to interact with the DBMS.

Simple Definition:

SQL is a language used to talk to a database.

2. Why SQL is Needed?

Without SQL, we cannot properly interact with relational databases.

SQL is needed for:

  • Creating databases and tables
  • Inserting data
  • Retrieving data
  • Updating records
  • Deleting records
  • Managing users and permissions
  • Performing calculations on data

Example Problem:

Suppose you want to find students who scored more than 80 marks. Without SQL, it would be very difficult. With SQL: 

SELECT Name, Marks
FROM Students
WHERE Marks > 80;

3. History of SQL

  • 1970 – Relational model proposed by E. F. Codd at IBM.
  • 1974 – SQL was developed by IBM (initially called SEQUEL).
  • 1986 – SQL became ANSI standard.
  • 1987 – SQL became ISO standard.
  • Later versions – SQL-92, SQL:1999, SQL:2003, SQL:2011 etc.
SQL was originally called SEQUEL (Structured English Query Language).

4. Features of SQL

1. Simple and Easy to Learn

Uses English-like commands.

2. Standard Language

Used worldwide with relational databases.

3. Portable

Works with MySQL, Oracle, SQL Server, PostgreSQL etc.

4. Supports Multiple Operations

  • DDL – Data Definition Language
  • DML – Data Manipulation Language
  • DCL – Data Control Language
  • TCL – Transaction Control Language

5. High Performance

Can handle large volumes of data efficiently.

5. SQL Standards

SQL follows international standards defined by:

  • ANSI (American National Standards Institute)
  • ISO (International Organization for Standardization)

Major SQL Standard Versions:

Version Year Features
SQL-86 1986 First Standard
SQL-92 1992 Improved Queries
SQL:1999 1999 Triggers, Stored Procedures
SQL:2003 2003 XML Support
SQL:2011 2011 Enhanced Features

6. Where SQL is Used?

1. Banking Systems

Account management and transactions.

2. E-commerce Websites

Product catalog, orders, customers.

3. College Management Systems

Student records, marks, attendance.

4. Social Media Platforms

User data, posts, comments.

5. Government Systems

Citizen records, taxation systems.

Simple SQL Query Example

-- Step 1: Create Table
CREATE TABLE Students (
    RollNo INT PRIMARY KEY,
    Name VARCHAR(50),
    Marks INT
);

-- Step 2: Insert Data
INSERT INTO Students VALUES (101, 'Rahul', 85);
INSERT INTO Students VALUES (102, 'Priya', 90);
INSERT INTO Students VALUES (103, 'Amit', 75);

-- Step 3: Retrieve Data
SELECT * FROM Students;

-- Step 4: Retrieve Students with Marks > 80
SELECT Name, Marks
FROM Students
WHERE Marks > 80;

This example shows how SQL creates, inserts, and retrieves data.
