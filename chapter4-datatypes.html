Chapter 4: SQL Data Types

What are SQL Data Types?

SQL Data Types define what kind of data can be stored in a column of a table. Choosing the correct data type improves performance and saves storage.

Each column in a table must have a defined data type.

1. Numeric Data Types

Used to store numbers.

1. INT (Integer)

Stores whole numbers.

CREATE TABLE Students (
    RollNo INT,
    Marks INT
);

2. SMALLINT

Stores small range integers.

CREATE TABLE AgeData (
    Age SMALLINT
);

3. BIGINT

Stores very large integers.

CREATE TABLE Population (
    Total BIGINT
);

4. DECIMAL(p,s)

Stores exact numeric values with precision and scale.

CREATE TABLE SalaryData (
    Salary DECIMAL(10,2)
);

5. FLOAT

Stores approximate decimal numbers.

CREATE TABLE Measurements (
    Temperature FLOAT
);

2. Character / String Data Types

1. CHAR(n)

Fixed length string.

CREATE TABLE Country (
    Code CHAR(3)
);

2. VARCHAR(n)

Variable length string.

CREATE TABLE Students (
    Name VARCHAR(50)
);

3. TEXT

Stores large text data.

CREATE TABLE Articles (
    Content TEXT
);

3. Date and Time Data Types

1. DATE

Stores date (YYYY-MM-DD).

CREATE TABLE Events (
    EventDate DATE
);

2. TIME

Stores time (HH:MM:SS).

CREATE TABLE Schedule (
    StartTime TIME
);

3. DATETIME

Stores both date and time.

CREATE TABLE Orders (
    OrderDate DATETIME
);

4. TIMESTAMP

Stores date and time with automatic update feature.

CREATE TABLE Logs (
    CreatedAt TIMESTAMP
);

4. Boolean Data Type

BOOLEAN / BOOL

Stores TRUE or FALSE values.

CREATE TABLE Users (
    IsActive BOOLEAN
);

5. Binary Data Types

1. BINARY(n)

Fixed length binary data.

CREATE TABLE EncryptionKeys (
    KeyValue BINARY(16)
);

2. VARBINARY(n)

Variable length binary data.

CREATE TABLE Files (
    FileData VARBINARY(255)
);

3. BLOB

Stores large binary objects like images or videos.

CREATE TABLE Images (
    Photo BLOB
);

Complete Example Table Using Multiple Data Types

CREATE TABLE Employees (
    EmpID INT PRIMARY KEY,
    Name VARCHAR(50),
    Age SMALLINT,
    Salary DECIMAL(10,2),
    JoiningDate DATE,
    LoginTime TIME,
    IsActive BOOLEAN,
    ProfileImage BLOB
);
