Chapter 5: SQL Constraints

What are SQL Constraints?

Constraints are rules applied to table columns to ensure data accuracy, reliability, and integrity. They prevent invalid data from being inserted into the database.

Constraints help maintain Data Integrity.

1. NOT NULL Constraint

Ensures that a column cannot store NULL values.

Syntax:

CREATE TABLE Students (
    RollNo INT,
    Name VARCHAR(50) NOT NULL
);

Example:

INSERT INTO Students (RollNo, Name)
VALUES (101, 'Rahul');   -- Valid

INSERT INTO Students (RollNo)
VALUES (102);            -- Error (Name cannot be NULL)

2. UNIQUE Constraint

Ensures that all values in a column are different. Duplicate values are not allowed.

Syntax:

CREATE TABLE Users (
    UserID INT,
    Email VARCHAR(100) UNIQUE
);

Example:

INSERT INTO Users VALUES (1, 'rahul@gmail.com');  -- Valid
INSERT INTO Users VALUES (2, 'rahul@gmail.com');  -- Error (Duplicate)
A UNIQUE column can allow one NULL value (depending on DBMS).

3. PRIMARY KEY Constraint

Uniquely identifies each record in a table. It cannot contain NULL values and must be unique.

Syntax:

CREATE TABLE Students (
    RollNo INT PRIMARY KEY,
    Name VARCHAR(50)
);

Composite Primary Key Example:

CREATE TABLE Enrollments (
    RollNo INT,
    CourseID INT,
    PRIMARY KEY (RollNo, CourseID)
);

4. FOREIGN KEY Constraint

Creates a relationship between two tables. It links one table to another using a key.

Syntax:

CREATE TABLE Courses (
    CourseID INT PRIMARY KEY,
    CourseName VARCHAR(50)
);

CREATE TABLE Enrollments (
    RollNo INT,
    CourseID INT,
    FOREIGN KEY (CourseID) REFERENCES Courses(CourseID)
);

Example:

INSERT INTO Courses VALUES (1, 'DBMS');

INSERT INTO Enrollments VALUES (101, 1);  -- Valid
INSERT INTO Enrollments VALUES (102, 5);  -- Error (CourseID 5 does not exist)

5. CHECK Constraint

Ensures that values satisfy a specific condition.

Syntax:

CREATE TABLE Students (
    RollNo INT,
    Marks INT CHECK (Marks >= 0 AND Marks <= 100)
);

Example:

INSERT INTO Students VALUES (101, 85);   -- Valid
INSERT INTO Students VALUES (102, 120);  -- Error

6. DEFAULT Constraint

Assigns a default value if no value is specified.

Syntax:

CREATE TABLE Employees (
    EmpID INT,
    Status VARCHAR(20) DEFAULT 'Active'
);

Example:

INSERT INTO Employees (EmpID) VALUES (1);

SELECT * FROM Employees;
-- Status will automatically be 'Active'

Difference Between PRIMARY KEY and UNIQUE

Feature PRIMARY KEY UNIQUE
Uniqueness Must be unique Must be unique
NULL Values Cannot contain NULL Can allow one NULL (DBMS dependent)
Number per Table Only one primary key Multiple UNIQUE allowed
Purpose Main identifier Alternate unique field
Used in Relationships Referenced by Foreign Key Generally not used for relationships

Complete Example Using All Constraints

CREATE TABLE Students (
    RollNo INT PRIMARY KEY,
    Name VARCHAR(50) NOT NULL,
    Email VARCHAR(100) UNIQUE,
    Age INT CHECK (Age >= 18),
    Status VARCHAR(20) DEFAULT 'Active'
);

CREATE TABLE Marks (
    RollNo INT,
    Subject VARCHAR(50),
    Score INT CHECK (Score BETWEEN 0 AND 100),
    PRIMARY KEY (RollNo, Subject),
    FOREIGN KEY (RollNo) REFERENCES Students(RollNo)
);
