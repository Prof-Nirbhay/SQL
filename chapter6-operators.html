Chapter 6: SQL Operators

What are SQL Operators?

SQL operators are special symbols or keywords used to perform operations on data. They are mainly used in the WHERE clause to filter records.

Operators help us apply conditions and calculations in SQL queries.

1. Arithmetic Operators

Used to perform mathematical calculations.

OperatorDescription
+Addition
-Subtraction
*Multiplication
/Division
%Modulus

Example:

SELECT Name, Marks, Marks + 5 AS BonusMarks
FROM Students;

SELECT 10 * 5 AS Result;

2. Comparison Operators

Used to compare two values.

OperatorDescription
=Equal
!= or <>Not Equal
>Greater Than
<Less Than
>=Greater Than or Equal
<=Less Than or Equal

Example:

SELECT * FROM Students
WHERE Marks >= 80;

3. Logical Operators

Used to combine multiple conditions.

OperatorDescription
ANDBoth conditions must be true
ORAt least one condition must be true
NOTReverses the condition

Example:

SELECT * FROM Students
WHERE Marks > 70 AND Age > 18;

SELECT * FROM Students
WHERE NOT Marks < 50;

4. BETWEEN Operator

Used to filter values within a range (inclusive).

Example:

SELECT * FROM Students
WHERE Marks BETWEEN 60 AND 90;

5. IN Operator

Used to match values from a given list.

Example:

SELECT * FROM Students
WHERE RollNo IN (101, 102, 105);

6. LIKE Operator

Used for pattern matching in text.

SymbolDescription
%Represents multiple characters
_Represents single character

Example:

SELECT * FROM Students
WHERE Name LIKE 'R%';   -- Names starting with R

SELECT * FROM Students
WHERE Name LIKE '_a%';  -- Second letter is 'a'

7. IS NULL Operator

Used to check NULL values.

Example:

SELECT * FROM Students
WHERE Email IS NULL;

SELECT * FROM Students
WHERE Email IS NOT NULL;

8. ANY Operator

Returns true if any value in the subquery satisfies the condition.

Example:

SELECT Name FROM Students
WHERE Marks > ANY (SELECT Marks FROM Students WHERE Age > 20);

9. ALL Operator

Returns true if the condition is true for all values in subquery.

Example:

SELECT Name FROM Students
WHERE Marks > ALL (SELECT Marks FROM Students WHERE Age > 20);

10. EXISTS Operator

Returns true if the subquery returns at least one record.

Example:

SELECT Name
FROM Students s
WHERE EXISTS (
    SELECT 1
    FROM Marks m
    WHERE m.RollNo = s.RollNo
);

Summary Table of Operators
