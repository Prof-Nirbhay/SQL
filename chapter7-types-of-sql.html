Chapter 7: Types of SQL Commands

Introduction

SQL commands are categorized into different types depending on their functionality. These categories help in organizing database operations efficiently.

Major Types of SQL Commands:
  • DDL – Data Definition Language
  • DML – Data Manipulation Language
  • DQL – Data Query Language
  • DCL – Data Control Language
  • TCL – Transaction Control Language

1. DDL – Data Definition Language

DDL commands are used to define and modify the structure of database objects such as tables, schemas, and indexes.

Common DDL Commands

CommandDescription
CREATECreate database or table
ALTERModify table structure
DROPDelete table or database
TRUNCATERemove all records from a table
RENAMERename database object

Example

-- Create Table
CREATE TABLE Students (
    RollNo INT PRIMARY KEY,
    Name VARCHAR(50),
    Marks INT
);

-- Modify Table
ALTER TABLE Students ADD Email VARCHAR(100);

-- Rename Table
RENAME TABLE Students TO StudentRecords;

-- Delete Table
DROP TABLE StudentRecords;

2. DML – Data Manipulation Language

DML commands are used to insert, modify, and delete records inside tables.

Common DML Commands

CommandDescription
INSERTAdd new records
UPDATEModify existing records
DELETERemove records

Examples

-- Insert Record
INSERT INTO Students VALUES (101, 'Rahul', 85);

-- Update Record
UPDATE Students
SET Marks = 90
WHERE RollNo = 101;

-- Delete Record
DELETE FROM Students
WHERE RollNo = 101;

3. DQL – Data Query Language

DQL commands are used to retrieve data from the database. The primary command used in DQL is SELECT.

SELECT Syntax

SELECT column1, column2
FROM table_name
WHERE condition;

Examples

-- Retrieve All Data
SELECT * FROM Students;

-- Retrieve Specific Columns
SELECT Name, Marks FROM Students;

-- Retrieve Data with Condition
SELECT * FROM Students
WHERE Marks > 80;

4. DCL – Data Control Language

DCL commands are used to control access and permissions in the database. These commands are mostly used by database administrators.

Common Commands

CommandDescription
GRANTProvide user access
REVOKERemove user access

Example

-- Give permission
GRANT SELECT ON Students TO user1;

-- Remove permission
REVOKE SELECT ON Students FROM user1;

5. TCL – Transaction Control Language

TCL commands manage database transactions. A transaction is a group of SQL statements executed together.

Common Commands

CommandDescription
COMMITSave changes permanently
ROLLBACKUndo changes
SAVEPOINTCreate rollback point

Example

INSERT INTO Students VALUES (102, 'Priya', 88);

SAVEPOINT A;

UPDATE Students
SET Marks = 95
WHERE RollNo = 102;

ROLLBACK TO A;

COMMIT;

Comparison of SQL Command Types

Type Purpose Commands
DDL Define database structure CREATE, ALTER, DROP
DML Modify data INSERT, UPDATE, DELETE
DQL Retrieve data SELECT
DCL Control permissions GRANT, REVOKE
TCL Manage transactions COMMIT, ROLLBACK, SAVEPOINT
