Chapter 8: SQL Clauses

What are SQL Clauses?

SQL Clauses are conditions or modifiers used in SQL queries to refine and control how data is retrieved from a database. They help filter, group, sort, and limit the results returned by SQL queries.

Clauses are mainly used with the SELECT statement to control the output of the query.

1. SELECT Clause

The SELECT clause is used to specify which columns should be retrieved from a table.

Syntax

SELECT column1, column2
FROM table_name;

Example

SELECT Name, Marks
FROM Students;

This query retrieves Name and Marks from the Students table.

2. FROM Clause

The FROM clause specifies the table from which the data will be retrieved.

Syntax

SELECT column_name
FROM table_name;

Example

SELECT *
FROM Students;

This query retrieves all columns from the Students table.

3. WHERE Clause

The WHERE clause is used to filter records based on specific conditions.

Syntax

SELECT column_name
FROM table_name
WHERE condition;

Example

SELECT *
FROM Students
WHERE Marks > 80;

This returns only students who scored more than 80 marks.

4. GROUP BY Clause

GROUP BY is used to group rows that have the same values in specified columns. It is often used with aggregate functions such as COUNT, SUM, AVG, MAX, and MIN.

Syntax

SELECT column_name, aggregate_function(column)
FROM table_name
GROUP BY column_name;

Example

SELECT Department, COUNT(*)
FROM Employees
GROUP BY Department;

This counts the number of employees in each department.

5. HAVING Clause

HAVING is used to filter grouped data after applying GROUP BY.

Syntax

SELECT column_name, aggregate_function(column)
FROM table_name
GROUP BY column_name
HAVING condition;

Example

SELECT Department, COUNT(*)
FROM Employees
GROUP BY Department
HAVING COUNT(*) > 5;

This returns departments having more than 5 employees.

6. ORDER BY Clause

ORDER BY is used to sort query results in ascending or descending order.

Syntax

SELECT column_name
FROM table_name
ORDER BY column_name ASC|DESC;

Example

SELECT Name, Marks
FROM Students
ORDER BY Marks DESC;

This sorts students by marks from highest to lowest.

7. DISTINCT Clause

DISTINCT is used to remove duplicate values from the result set.

Syntax

SELECT DISTINCT column_name
FROM table_name;

Example

SELECT DISTINCT Department
FROM Employees;

This retrieves unique department names.

8. LIMIT Clause

LIMIT restricts the number of rows returned by a query. It is commonly used in MySQL and PostgreSQL.

Syntax

SELECT column_name
FROM table_name
LIMIT number;

Example

SELECT *
FROM Students
LIMIT 5;

This returns only the first 5 rows from the table.

Execution Order of SQL Clauses

Although SQL queries are written in a specific order, they are executed by the database in a different logical order.

Execution Order Clause Purpose
1 FROM Select table
2 WHERE Filter rows
3 GROUP BY Group records
4 HAVING Filter groups
5 SELECT Select columns
6 DISTINCT Remove duplicates
7 ORDER BY Sort result
8 LIMIT Limit output rows

Example Query Using Multiple Clauses

SELECT Department, COUNT(*) AS TotalEmployees
FROM Employees
WHERE Salary > 30000
GROUP BY Department
HAVING COUNT(*) > 3
ORDER BY TotalEmployees DESC
LIMIT 5;

This query finds the top 5 departments with more than 3 employees who earn more than 30000.
