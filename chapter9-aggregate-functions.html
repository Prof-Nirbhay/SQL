Chapter 9: SQL Aggregate Functions

What are Aggregate Functions?

Aggregate functions perform calculations on multiple rows of a table and return a single summarized value. These functions are commonly used in reports and data analysis.

Aggregate functions are often used with GROUP BY and HAVING clauses.

List of Common Aggregate Functions

Function Description
COUNT() Counts number of rows
SUM() Calculates total value
AVG() Calculates average value
MIN() Returns smallest value
MAX() Returns largest value

1. COUNT Function

COUNT() returns the total number of rows in a table.

Syntax

SELECT COUNT(column_name)
FROM table_name;

Example

SELECT COUNT(*) 
FROM Students;

This returns the total number of students.

2. SUM Function

SUM() calculates the total of a numeric column.

Syntax

SELECT SUM(column_name)
FROM table_name;

Example

SELECT SUM(Marks)
FROM Students;

This returns total marks of all students.

3. AVG Function

AVG() calculates the average value of a column.

Syntax

SELECT AVG(column_name)
FROM table_name;

Example

SELECT AVG(Marks)
FROM Students;

This returns average marks.

4. MIN Function

MIN() returns the smallest value in a column.

Syntax

SELECT MIN(column_name)
FROM table_name;

Example

SELECT MIN(Marks)
FROM Students;

This returns lowest marks.

5. MAX Function

MAX() returns the largest value in a column.

Syntax

SELECT MAX(column_name)
FROM table_name;

Example

SELECT MAX(Marks)
FROM Students;

This returns highest marks.

Using Aggregate Functions with GROUP BY

GROUP BY groups rows with the same values and allows aggregate functions to calculate results for each group.

Example

SELECT Department, AVG(Marks)
FROM Students
GROUP BY Department;

This calculates the average marks for each department.

Using Aggregate Functions with HAVING

HAVING is used to filter grouped data after applying aggregate functions.

Example

SELECT Department, AVG(Marks)
FROM Students
GROUP BY Department
HAVING AVG(Marks) > 80;

This returns only departments whose average marks are greater than 80.

Nested SQL Functions

Nested functions occur when one SQL function is used inside another function.

Example

SELECT MAX(AVG(Marks))
FROM Students
GROUP BY Department;

Explanation:

  • First AVG(Marks) calculates average marks for each department.
  • Then MAX() finds the highest average among departments.

Another Nested Function Example

SELECT ROUND(AVG(Marks))
FROM Students;

Here:

  • AVG() calculates average marks.
  • ROUND() rounds the average value.
