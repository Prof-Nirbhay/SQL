Advanced Excel Topics with Explanation

What If Analysis

Goal Seek

Goal Seek helps you find the input value needed to achieve a desired result.

Example: If total = Price × Quantity, and you want total = 5000:

Formula: =A1*B1
Use Goal Seek to set result to 5000 by changing Quantity.

Scenario Analysis

Used to compare different sets of values.

Example: Best Case, Worst Case, Expected Case for sales.

Data Tables

Used for sensitivity analysis.

Formula: =A1*B1
Change multiple values of A1 or B1 to see impact.

Solver Tool

Used for optimization problems.

Example: Maximize profit by adjusting cost variables.
Logical Functions

IF Function

Checks a condition and returns value based on TRUE/FALSE.

Formula: =IF(A1>50,"Pass","Fail")

IFERROR

Handles errors in formulas.

Formula: =IFERROR(A1/B1,"Error")

Nested IF

Multiple conditions inside IF.

=IF(A1>80,"A",IF(A1>60,"B","C"))

AND / OR

Used with IF for multiple conditions.

=IF(AND(A1>50,B1>50),"Pass","Fail")
Data Validation

Number, Date & Time Validation

Restrict user input.

Allow numbers between 1–100.

Text and List Validation

Create dropdown lists.

List: Apple, Mango, Banana

Custom Validation

Use formulas to validate input.

=A1>10

Dynamic Dropdown

Create dependent dropdown lists.

Select Country → Shows related Cities
Lookup Functions

VLOOKUP / HLOOKUP

Search value in a table.

=VLOOKUP(A1, A2:C10, 2, FALSE)

INDEX and MATCH

Advanced lookup method.

=INDEX(B2:B10, MATCH(A1, A2:A10, 0))

Nested VLOOKUP

Use VLOOKUP inside another.

=VLOOKUP(VLOOKUP(A1, A2:B10, 2, FALSE), D2:F10, 2, FALSE)

Reverse Lookup

Lookup from right to left.

=VLOOKUP(A1, CHOOSE({1,2}, B2:B10, A2:A10), 2, FALSE)

INDIRECT with VLOOKUP

Dynamic sheet reference.

=VLOOKUP(A1, INDIRECT("Sheet2!A2:C10"), 2, FALSE)
