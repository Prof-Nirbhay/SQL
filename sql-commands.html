SQL Commands (DDL, DML, DCL, TCL)

Introduction

SQL commands are divided into four major categories based on their function:

  • DDL – Data Definition Language
  • DML – Data Manipulation Language
  • DCL – Data Control Language
  • TCL – Transaction Control Language

1. DDL – Data Definition Language

DDL commands are used to define and modify the structure of database objects like tables, databases, and indexes.

Common DDL Commands

Command Purpose
CREATE Create database or table
ALTER Modify table structure
DROP Delete table/database
TRUNCATE Delete all records (no rollback)

Examples

-- Create Database
CREATE DATABASE College;

-- Create Table with Constraints
CREATE TABLE Students (
    RollNo INT PRIMARY KEY,
    Name VARCHAR(50) NOT NULL,
    Marks INT CHECK (Marks >= 0),
    Email VARCHAR(100) UNIQUE
);

-- Add New Column
ALTER TABLE Students ADD Age INT;

-- Remove Column
ALTER TABLE Students DROP COLUMN Age;

-- Delete Table
DROP TABLE Students;
DDL commands automatically commit changes.

2. DML – Data Manipulation Language

DML commands are used to manage data inside tables.

Common DML Commands

Command Purpose
INSERT Add new record
SELECT Retrieve data
UPDATE Modify data
DELETE Remove record

Examples

-- Insert Data
INSERT INTO Students VALUES (101, 'Rahul', 85, 'rahul@gmail.com');

-- Select All Records
SELECT * FROM Students;

-- Select Specific Columns
SELECT Name, Marks FROM Students WHERE Marks > 80;

-- Update Data
UPDATE Students
SET Marks = 90
WHERE RollNo = 101;

-- Delete Record
DELETE FROM Students
WHERE RollNo = 101;
DML commands can be controlled using COMMIT and ROLLBACK.

3. DCL – Data Control Language

DCL commands control user access and permissions.

Common DCL Commands

Command Purpose
GRANT Give permission
REVOKE Remove permission

Examples

-- Give SELECT permission
GRANT SELECT ON Students TO user1;

-- Give Full Access
GRANT ALL PRIVILEGES ON Students TO user1;

-- Remove Permission
REVOKE SELECT ON Students FROM user1;

4. TCL – Transaction Control Language

TCL commands manage transactions. A transaction is a group of SQL statements executed as a single unit.

Common TCL Commands

Command Purpose
COMMIT Save changes permanently
ROLLBACK Undo changes
SAVEPOINT Create rollback point

Example

INSERT INTO Students VALUES (102, 'Priya', 88, 'priya@gmail.com');

SAVEPOINT A;

UPDATE Students SET Marks = 95 WHERE RollNo = 102;

ROLLBACK TO A;

COMMIT;
TCL ensures data consistency using ACID properties.

Important SQL Constraints

Constraints are rules applied on table columns to maintain data integrity.

Constraint Description
PRIMARY KEY Uniquely identifies each record
FOREIGN KEY Creates relationship between tables
NOT NULL Prevents NULL values
UNIQUE Ensures all values are different
CHECK Validates condition
DEFAULT Sets default value

Constraint Example

CREATE TABLE Courses (
    CourseID INT PRIMARY KEY,
    CourseName VARCHAR(50) NOT NULL,
    Credits INT CHECK (Credits > 0),
    Status VARCHAR(20) DEFAULT 'Active'
);

CREATE TABLE Enrollments (
    RollNo INT,
    CourseID INT,
    PRIMARY KEY (RollNo, CourseID),
    FOREIGN KEY (CourseID) REFERENCES Courses(CourseID)
);

Comparison of SQL Command Types

Type Full Form Used For Examples
DDL Data Definition Language Structure CREATE, ALTER, DROP
DML Data Manipulation Language Data Operations INSERT, SELECT, UPDATE, DELETE
DCL Data Control Language Permissions GRANT, REVOKE
TCL Transaction Control Language Transactions COMMIT, ROLLBACK
